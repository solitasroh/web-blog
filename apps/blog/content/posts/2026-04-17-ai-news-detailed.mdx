### 10. Zerobox: OpenAI Codex 런타임 기반 샌드박싱 도구

**출처**: [GitHub](https://github.com/afshinm/zerobox) | GeekNews 2pts

Codex의 샌드박스 런타임을 독립 도구로 추출한 경량 프로세스 격리 도구.

**핵심 기능**
| 기능 | 설명 |
|------|------|
| **Deny by default** | 쓰기, 네트워크, 환경변수 기본 차단 |
| **Credential injection** | API 키를 프로세스가 직접 보지 못하게 주입 |
| **File access control** | 특정 경로 읽기/쓰기 허용/차단 |
| **Network filtering** | 도메인별 아웃바운드 트래픽 제어 |
| **Cross-platform** | macOS, Linux (Windows 계획) |
| **Single binary** | Docker 없이 ~10ms 오버헤드 |

**SDK 지원**
- Rust SDK: `zerobox::Sandbox` with builder API
- TypeScript SDK: `import { Sandbox } from "zerobox"`

**설치**
```bash
curl -fsSL https://raw.githubusercontent.com/afshinm/zerobox/main/install.sh | sh
# 또는
npm install -g zerobox
```

### 11. pi-autoresearch: Karpathy의 "AI 자율 실험" 아이디어 범용화

**출처**: [GitHub](https://github.com/davebcn87/pi-autoresearch) | GeekNews 7pts

터미널 AI 코딩 에이전트 pi의 확장으로, Karpathy의 autoresearch 아이디어를 범용화한 오픈소스.

**개념**
> "Try an idea, measure it, keep what works, discard what doesn't, repeat forever"
> (아이디어를 시도하고 → 측정하고 → 개선되면 유지, 아니면 버리고 → 영원히 반복)

**도구**
| 도구 | 설명 |
|------|------|
| `init_experiment` | 세션 설정 - 이름, 메트릭, 단위, 방향 |
| `run_experiment` | 명령 실행, 실행 시간 측정, 출력 캡처 |
| `log_experiment` | 결과 기록, 자동 커밋, 위젯/대시보드 업데이트 |

**활용 예시**
- 테스트 속도 최적화
- 번들 사이즈 최적화
- LLM 트레이닝
- 빌드 시간 최적화
- Lighthouse 점수 개선

**설치**
```bash
pi install https://github.com/davebcn87/pi-autoresearch
```
